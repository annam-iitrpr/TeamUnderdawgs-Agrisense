# Decisions

1. Import the exact inspected existing app snapshot into the empty destination. Exclude README/environment files and unreviewed historical objects. Preserve source attribution in contract handoff.
2. Publish `contract_v1` early, as requested, while reserving `agrisense-contract-v1` for the fully verified bootstrap gate.
3. Keep Phase 1/2-owned paths unchanged after initial import. All interface changes are additive and regenerated by Phase 3.
4. Supplied secrets remain outside Git; scanner compares staged contents against local secret values without printing them.
5. Disable inherited unauthenticated legacy routes in the new application entrypoint; any compatibility adapter must authorize using the same Firebase path.
